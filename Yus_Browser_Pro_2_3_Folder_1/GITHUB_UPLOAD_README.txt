Yus Browser Pro 2.3 — Folder 1

1) Распакуйте весь ZIP в отдельную папку. Не запускайте main.py прямо из архива.
2) Для установки зависимостей запустите INSTALL_DEPENDENCIES.bat. Нужен Python и интернет.
3) Для запуска откройте START_YUS_BROWSER.bat. Если приложение не запускается, оставьте окно открытым и сохраните текст ошибки.
4) Чтобы собрать Windows-приложение, запустите BUILD_STANDALONE_APP.bat; итог сборки ищите в папке dist.
5) Для GitHub загрузите файлы из этой папки в Repository. Не загружайте пароли, токены или личные файлы.

Важно: архив и синтаксис Python проверены на целостность; фактический запуск в Windows здесь не выполнялся. Для полноценного запуска нужны совместимый Python и интернет для установки зависимостей.
